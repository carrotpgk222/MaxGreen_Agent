PUT YOUR GOOGLE OAUTH FILE HERE

1. Download the OAuth Desktop App JSON file from Google Cloud.
2. Rename it exactly to: credentials.json
3. Put it in this folder.
4. Run ../connect_gmail.bat

After you authorize Gmail, token.json will appear here automatically.

PRIVATE FILES:
- credentials.json
- token.json

Never upload these files to GitHub and never send them to ChatGPT or another person.
